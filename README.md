## Shiny note
GitHub Pages cannot run a live Shiny app. The ICU project page includes a static app preview and links to the report and `app.R`. To make it fully interactive, deploy the app on shinyapps.io, Posit Connect, or another Shiny server and replace the source-code link with the deployed app URL.
